1. 封面（含本頁 QR code）

4. 數字說話：WHO 22 億／10 億、新北 ICOPE 最常見異常是視力、台灣白內障就醫人數
5. 正常老化 vs 警訊
6. 四種常見眼疾「看出去的樣子」（互動切換）
7. 自我觀察清單（可勾選，紅框為立刻就醫警訊）
8. 家人與照顧者怎麼觀察＋在家三招
9. 阿姆斯勒方格表六步驟與異常樣態
10. 立刻就醫的紅燈
11. 多久看一次醫生（AAO 2020、健保糖尿病品質指標）
12. 每天護眼六件事（與作業單相同）
13. 餐桌與居家：飲食、光線、安全
